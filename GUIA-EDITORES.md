# Cómo crear una sección nueva en Chupis

Esta guía es para las personas que escriben secciones nuevas. No hace falta saber programar.

## Antes de empezar (solo la primera vez)

1. Acepta la invitación al repositorio de GitHub que te llegará por correo.
2. Crea un token personal. Es como una contraseña que solo sirve para este proyecto:
   1. En GitHub, pulsa tu foto, luego **Settings**.
   2. Abajo del todo, **Developer settings**, luego **Personal access tokens**, luego **Tokens (classic)**.
   3. Pulsa **Generate new token (classic)**.
   4. En **Note** escribe `Editor Chupis` y elige una caducidad.
   5. Marca el permiso `public_repo` si el repositorio es público, o `repo` si es privado.
   6. Pulsa **Generate token** y copia el texto que empieza por `ghp_`. No se vuelve a mostrar.
3. Guárdalo en un gestor de contraseñas. No se lo des a nadie.

## Entrar al editor

1. Abre `https://TU-SITIO.neocities.org/admin/`.
2. Elige iniciar sesión con GitHub mediante token y pega el tuyo.

## Crear una sección

1. Pulsa **Secciones nuevas** y luego **New** (nueva).
2. Rellena los campos:
   - **Título:** aparece en el menú y como encabezado de la página.
   - **Descripción corta:** una frase para los buscadores. Es opcional.
   - **Color de fondo:** el color del texto y de los enlaces se ajusta solo.
   - **Mostrar en el menú:** desmárcalo para una página que solo se alcance por enlace.
   - **Contenido:** escribe aquí, con negrita, cursiva, enlaces, subtítulos, citas y listas.
3. Para añadir una imagen, pulsa el botón de imagen del editor y sube el archivo. Mejor que pese menos de 1 MB.
4. Pulsa **Save** (guardar). La sección se publica sola en uno o tres minutos.

## Cambiar una sección

Entra, pulsa la sección en la lista, edita y pulsa **Save**.

## Qué no se puede hacer

- Cambiar el color o el tamaño de una parte del texto. Solo cambia el fondo de la página entera.
- Editar las secciones antiguas. Solo aparecen en el editor las que se crean desde él.

## Si algo falla

- **No me deja entrar:** el token está mal copiado, ha caducado o no tiene el permiso. Crea uno nuevo.
- **No aparece mi sección:** espera tres minutos y refresca con Ctrl+F5. Si sigue sin salir, avisa a quien administra el sitio.
