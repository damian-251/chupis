¿Qué permisos necesita el token?

En un token de acceso detallado, selecciona este repositorio y concede permiso de lectura y escritura en Contents. Un token clásico necesita public_repo si el repositorio es público o repo si es privado. No compartas el token ni lo incluyas en capturas.
